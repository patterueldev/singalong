## Quick Start (Python - Recommended)

### Step 1: Install Dependencies

```bash
pip install websockets httpx
```

### Step 2: Create Test Script

Create a file named `test_ws.py`:

```python
import asyncio
import json
import httpx
import websockets

async def main():
    print("=" * 70)
    print("W2.4 WebSocket Testing")
    print("=" * 70)
    
    # Step 1: Get JWT token
    print("\n[STEP 1] Getting JWT token...")
    async with httpx.AsyncClient() as client:
        response = await client.post(
            "http://localhost:5002/api/auth/controller",
            json={
                "nickname": "Test User",
                "session_id": "9999"
            }
        )
        
        if response.status_code != 201:
            print(f"✗ Failed to get token: {response.status_code}")
            print(f"  Response: {response.text}")
            return
        
        token = response.json()["access_token"]
        print(f"✓ Got token")
        print(f"  Session: 9999")
        print(f"  Token: {token[:60]}...")
    
    # Step 2: Connect WebSocket
    print("\n[STEP 2] Connecting to WebSocket...")
    uri = "ws://localhost:5002/ws/9999"
    headers = {"Authorization": f"Bearer {token}"}
    
    try:
        async with websockets.connect(uri, extra_headers=headers) as ws:
            print(f"✓ Connected to {uri}")
            print("\n[STEP 3] Listening for events...")
            print("  (Press Ctrl+C to stop)\n")
            
            while True:
                try:
                    # Wait up to 30 seconds for an event
                    message = await asyncio.wait_for(ws.recv(), timeout=30)
                    data = json.loads(message)
                    
                    # Print the event
                    print(f"[EVENT] {data.get('type')}")
                    print(f"  Timestamp: {data.get('timestamp')}")
                    print(f"  Data: {json.dumps(data.get('data'), indent=2)}\n")
                    
                except asyncio.TimeoutError:
                    print("[INFO] No events in 30 seconds (connection still alive)\n")
                    
                except json.JSONDecodeError as e:
                    print(f"[ERROR] Invalid JSON: {message}\n")
                    
    except Exception as e:
        print(f"✗ Connection failed: {type(e).__name__}: {e}")
        return
    except KeyboardInterrupt:
        print("\n\n[INFO] Disconnected")
        print("=" * 70)

if __name__ == "__main__":
    asyncio.run(main())
```

### Step 3: Run the Test

```bash
python3 test_ws.py
```

## Testing with Postman

### Prerequisites
- Postman v10.0 or later (must support WebSocket)

### Step 1: Get JWT Token

1. Create a new **HTTP Request**
2. Set method to **POST**
3. URL: `http://localhost:5002/api/auth/controller`
4. Go to **Body** tab, select **raw**, choose **JSON**
5. Paste:
```json
{
  "nickname": "Test User",
  "session_id": "9999"
}
```
6. Click **Send**
7. Copy the `access_token` from the response

### Step 2: Create WebSocket Request

1. Click **+** to create new request
2. Click on the method dropdown → scroll down → select **WebSocket**
3. Paste URL: `ws://localhost:5002/ws/9999`
4. Go to **Headers** tab
5. Add header:
   - **Key**: `Authorization`
   - **Value**: `Bearer {paste_your_token_here}`
6. Click **Connect**
7. You should see a green "Connected" indicator
8. Watch the message panel below for events

### Step 3: Monitor Events

The message panel will show any events broadcast to your session:

```json
{
  "type": "song:playing",
  "data": {
    "song_id": "abc123",
    "title": "Never Gonna Give You Up",
    "artist": "Rick Astley",
    "duration_seconds": 252
  },
  "timestamp": "2026-05-02T12:00:00Z"
}
```

## Testing with curl + websocat

### Prerequisites

```bash
# Install websocat (if not already installed)
brew install websocat  # macOS
# or apt-get install websocat (Linux)
```

### Steps

```bash
# Step 1: Get JWT token
TOKEN=$(curl -s -X POST http://localhost:5002/api/auth/controller \
  -H "Content-Type: application/json" \
  -d '{
    "nickname": "Test User",
    "session_id": "9999"
  }' | jq -r '.access_token')

echo "Token: $TOKEN"

# Step 2: Connect to WebSocket
websocat -H "Authorization: Bearer $TOKEN" "ws://localhost:5002/ws/9999"

# You'll see events appear as they happen
# Press Ctrl+C to disconnect
```

## Troubleshooting

### "Unauthorized" (403)

**Problem**: Connection rejected with "Unauthorized"

**Solution**: 
- Verify Authorization header is set correctly
- Check token format: `Bearer {token}` (note the space)
- Get a fresh token - tokens expire after 3 hours

### "Connection refused"

**Problem**: Can't connect to WebSocket

**Solution**:
```bash
# Check if Node is running
docker-compose ps node

# Check Node logs for errors
docker-compose logs node | tail -20

# Make sure Node is on port 5002
curl http://localhost:5002/health
```

### "Invalid session"

**Problem**: Connection fails with "Session not found"

**Solution**:
- Use session `9999` (this always exists - it's the admin session)
- If you want to test with another session, create it first via the REST API

### No events after 30 seconds

**Problem**: Timeout messages keep appearing

**Solution**: This is **normal**! Events only broadcast when:
- A song starts playing
- The queue changes
- A download progresses
- An admin joins/leaves the session

If you want to see an event, you'll need to:
1. Open another terminal/Bruno request
2. Make an API call to trigger an event (e.g., add to queue)
3. Watch the WebSocket client receive it

### Connection drops after a few minutes

**Problem**: WebSocket disconnects unexpectedly

**Solution**:
- Token might be expired (valid for 3 hours)
- Network issue (try reconnecting)
- Browser closed or tab went to background
- Server restarted (check docker logs)
